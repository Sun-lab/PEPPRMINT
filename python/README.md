## Python codes

- PEPPRMINT.py: code to train the PEPPRMINT model for multi-allele data.

- pMHCpan.py: code to train a single-allele model for HLA-peptide interactions, to provide initial esimate for PEPPRMINT.

- _prediction_PEPPRMINT.py: code to run prediction using one model trained by PEPPRMINT.

- _predict.sh: a shell script to run _prediction_PEPPRMINT.py for all models.
